## 一、产品概述

### 1.1 产品定位

**产品名称**：LiveHub - 动态照片转换工具

**产品愿景**：成为跨平台、跨厂商的动态照片格式转换标准工具，让用户摆脱格式壁垒，自由分享动态照片。

**核心价值**：
- **打破格式壁垒**：解决各厂商动态照片格式互不兼容的问题
- **跨平台支持**：首个MVP聚焦HarmonyOS，后续扩展Android/iOS/Web
- **用户友好**：一键转换，批量处理，后台运行

### 1.2 目标用户

| 用户群体 | 核心需求 | 使用场景 |
|---------|---------|---------|
| **华为手机用户** | 将华为动态照片分享到其他平台 | 分享到抖音、快手、朋友圈 |
| **小米手机用户** | 将小米实况照片转换为通用格式 | 跨设备分享、云存储备份 |
| **iPhone用户** | 在HarmonyOS设备上查看Apple实况照片 | 接收iPhone用户分享的照片 |
| **摄影爱好者** | 批量处理动态照片、保留元数据 | 作品管理、跨平台发布 |

### 1.3 竞品分析

| 竞品 | 平台 | 支持格式 | 不足 | LiveHub优势 |
|------|------|---------|------|------------|
| **MotionPhotoMuxer** | 命令行 | Google/Samsung | 无GUI、技术门槛高 | HarmonyOS原生应用、UI友好 |
| **ExifTool** | 命令行 | 全格式 | 无转换功能、仅元数据 | 格式转换+元数据保留 |
| **各厂商相册APP** | 原生平台 | 仅自家格式 | 格式封闭 | 跨厂商转换 |
| **第三方转换工具** | 多平台 | 部分格式 | 不支持华为/小米 | 全5种格式支持 |

## 二、功能需求

### 2.1 核心功能（MVP P0）

#### 2.1.1 格式检测

**需求描述**：自动识别输入照片的动态照片格式

**支持格式**：
| 格式 | 中文名称 | 文件模式 | 检测优先级 |
|------|---------|---------|-----------|
| Apple Live Photo | Apple实况照片 | 分离文件 | P0 |
| 华为 Moving Photo | 华为动态照片 | 分离文件 | P0 |
| 小米 Live Photo | 小米实况照片 | 分离/嵌入 | P0 |
| Google Motion Photo | Google动态照片 | 嵌入文件 | P0 |
| Samsung Motion Photo | Samsung动态照片 | 嵌入文件 | P1 |

**检测流程**：
```
输入照片 → 格式检测引擎 → 返回格式类型 + 文件模式 + 资源位置
```

**验收标准**：
- [ ] Apple Live Photo检测准确率 ≥ 99%
- [ ] 华为 Moving Photo检测准确率 ≥ 99%
- [ ] 小米 Live Photo检测准确率 ≥ 95%（待实测验证）
- [ ] Google Motion Photo检测准确率 ≥ 99%
- [ ] Samsung Motion Photo检测准确率 ≥ 95%

#### 2.1.2 格式转换

**需求描述**：将输入格式转换为用户指定的输出格式

**转换矩阵**：

| 输入→输出 | Apple | 华为 | 小米 | Google | Samsung | 双输出兜底 |
|----------|-------|------|------|--------|---------|-----------|
| **Apple** | — | ⚠️XMP替代 | ⚠️分离文件 | ✅libmphoto | ✅libmphoto | ✅ |
| **华为** | ✅FFmpeg | ⚠️XMP替代 | ⚠️分离文件 | ✅libmphoto | ✅libmphoto | ✅ |
| **小米(分离)** | ✅FFmpeg | ⚠️XMP替代 | — | ✅ | ✅ | ✅ |
| **小米(嵌入)** | ✅FFmpeg+提取 | ⚠️XMP替代 | — | ✅ | ✅ | ✅ |
| **Google** | ✅FFmpeg+提取 | ⚠️XMP替代 | ⚠️嵌入 | — | ✅ | ✅ |
| **Samsung** | ✅FFmpeg+提取 | ⚠️XMP替代 | ⚠️嵌入 | ✅ | — | ✅ |

**关键转换路径**：

**华为 → Apple**：
```
1. HarmonyOS API提取JPG + MP4
2. FFmpeg MP4 → MOV转换（-tag:v hvc1）
3. 生成ContentIdentifier UUID
4. 写入QuickTime元数据
5. 输出：HEIC + MOV
```

**Google → Apple**：
```
1. GContainer:ItemLength定位视频
2. 提取嵌入MP4
3. FFmpeg MP4 → MOV转换
4. 写入ContentIdentifier
5. 输出：HEIC + MOV
```

**华为 → Google**：
```
1. 提取JPG + MP4
2. libmphoto创建Motion Photo
3. 写入GContainer元数据
4. 输出：单文件JPG（内嵌MP4）
```

**验收标准**：
- [ ] 华为 → Apple转换成功率 ≥ 95%
- [ ] Google → Apple转换成功率 ≥ 99%
- [ ] 华为 → Google转换成功率 ≥ 95%
- [ ] 转换后文件可被目标平台识别播放

#### 2.1.3 批量转换

**需求描述**：支持批量选择照片、批量转换

**功能要点**：
- 照片选择器：支持多选、全选
- 批量转换：后台任务执行
- 进度显示：实时进度、已完成数量
- 断点续传：任务中断后可恢复

**验收标准**：
- [ ] 支持选择 ≥ 50张照片
- [ ] 批量转换进度实时更新
- [ ] 任务中断后可恢复

#### 2.1.4 元数据保留

**需求描述**：转换过程中保留原始照片元数据

**保留元数据**：
| 元数据类型 | 保留策略 |
|-----------|---------|
| EXIF（拍摄参数） | ✅ 完全保留 |
| EXIF（GPS位置） | ✅ 完全保留（用户可选清除） |
| EXIF（时间戳） | ✅ 完全保留 |
| XMP（描述、标签） | ✅ 完全保留 |
| MakerNotes | ⚠️ 仅保留可读部分 |

**验收标准**：
- [ ] EXIF核心字段保留率 ≥ 99%
- [ ] XMP核心字段保留率 ≥ 95%

### 2.2 辅助功能（MVP P1）

#### 2.2.1 照片预览

**需求描述**：转换前后预览动态照片效果

**功能要点**：
- 静态帧预览：显示主照片
- 动态预览：播放3秒动态效果
- 对比预览：转换前后对比

#### 2.2.2 输出设置

**需求描述**：用户可配置输出参数

**可配置项**：
| 配置项 | 可选值 | 默认值 |
|-------|-------|-------|
| 输出格式 | Apple/华为/小米/Google/Samsung/双输出 | Google（兼容性最好） |
| 视频编码 | H.264/HEVC | 保持原始编码 |
| 输出目录 | 沙箱/相册 | 相册 |
| 文件命名 | 保持原名/自定义 | 保持原名 |

#### 2.2.3 历史记录

**需求描述**：记录转换历史，支持快速查看

**功能要点**：
- 转换历史列表
- 原始格式 → 输出格式显示
- 转换时间记录
- 快速重新转换

## 三、非功能需求

### 3.1 性能要求

| 性能指标 | 目标值 | 测试方法 |
|---------|-------|---------|
| 单张转换时间 | ≤ 5秒 | 10MB动态照片实测 |
| 批量转换（50张） | ≤ 3分钟 | 后台任务实测 |
| 格式检测时间 | ≤ 1秒 | 单张照片实测 |
| 内存占用 | ≤ 200MB | 批量转换峰值监控 |
| 应用启动时间 | ≤ 2秒 | 冷启动实测 |

### 3.2 兼容性要求

| 兼容性维度 | 要求 |
|-----------|-----|
| **HarmonyOS版本** | HarmonyOS 4.0+ |
| **设备类型** | 手机、平板 |
| **输入格式** | Apple/华为/小米/Google/Samsung动态照片 |
| **输出格式** | 同上 + 双输出兜底 |
| **视频编码** | H.264、HEVC |
| **图片编码** | JPEG、HEIC |

### 3.3 安全要求

| 安全维度 | 要求 |
|---------|-----|
| **数据安全** | 转换过程不泄露照片内容 |
| **权限最小化** | 仅申请必要权限（读写相册） |
| **用户隐私** | GPS信息可选清除 |
| **第三方库合规** | LGPL/MIT/BSD许可证声明 |

### 3.4 可用性要求

| 可用性维度 | 要求 |
|-----------|-----|
| **界面简洁** | 3步完成转换（选择→设置→转换） |
| **错误提示** | 清晰的错误信息 + 解决建议 |
| **进度反馈** | 实时进度 + 预估剩余时间 |
| **离线使用** | 无需网络连接 |

## 四、技术约束

### 4.1 已确认的技术限制

| 限制 | 影响 | 解决方案 |
|------|------|---------|
| **HarmonyOS不支持MOV输出** | Apple输出需要MOV | FFmpeg LGPL集成 |
| **iOS不接受MP4实况照片** | Apple输出必须MOV | FFmpeg remux必需 |
| **MakerNotes不可写** | 华为原生格式输出受限 | XMP替代方案 |
| **GContainer:ItemLength新规范** | Google格式提取需更新 | 优先ItemLength定位 |

### 4.2 第三方库依赖

| 库名 | 版本 | 许可证 | 用途 | 集成方式 |
|------|------|-------|------|---------|
| **FFmpeg** | 5.1.x | LGPL v2.1+ | MP4→MOV转换 | 动态链接 |
| **libmphoto** | 1.x | MIT | Google/Samsung格式处理 | 静态链接 |
| **Adobe XMP Toolkit** | 202x.x | BSD 3-Clause | XMP元数据处理 | 静态链接 |

### 4.3 待验证事项

| 验证项 | 状态 | 验证方法 |
|-------|-----|---------|
| 小米格式结构 | ⏳ 待实测 | ExifTool分析用户文件 |
| MakerNotes写入能力 | ⏳ 待真机测试 | HarmonyOS Native API测试 |
| libmphoto协议类型 | ⏳ 待确认 | GitHub LICENSE查看 |

## 六、风险与缓解

### 6.1 高风险

| 风险 | 严重度 | 可能性 | 缓解措施 |
|------|-------|-------|---------|
| **HEVC MOV在iOS不识别** | Critical | High | FFmpeg `-tag:v hvc1`参数 |
| **华为格式无法原生输出** | Critical | High | XMP替代 + 双输出兜底 |
| **小米格式未知** | Critical | Medium | 需用户提供文件实测 |

### 6.2 中风险

| 风险 | 严重度 | 可能性 | 缓解措施 |
|------|-------|-------|---------|
| XMP写入能力有限 | Major | High | Adobe XMP Toolkit集成 |
| 后台任务时长限制 | Major | Medium | 分片处理 + 断点续传 |
| 内存压力 | Major | Low | 限制批量数量 |
